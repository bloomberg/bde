BDE 4.35.0 Release

Schedule

  • The BDE team announces that the BDE 4.35.0 production release was completed on Tuesday, February 17, 2026.

BDE 4.35.0 Release Highlights

This release consists of assorted minor fixes.

Fixed Tickets

Summary

Please create an overloaded operator/ for filesystem::path

balb::FileCleanerConfiguration provide setMaxNumFiles?

Fix up doc and C++14 SFINAE support in pair

Improve the documentation for the implementation-detail types that define bsl::pair

Remove vestigial macros configuring bslstl_pair.h

Simplify the implementation and test driver for bsl::pair by assuming full language support implies full library support

Please address clang-20 nightly build test run error in bslstl_function_invokerutil.t

Apply test allocator pattern to bslfmt test driver main functions

ThreadSanitzer race in bdlcc::SkipList

Fix check_cycles execution errors on Windows

Replace include of deprecated bslma_stdalloator.h with supported bslma_bslallocator,h

Add for-testing-only includes to bslfmt package

Complete removal of failed experimental macro BSLS_LIBRARYFEATURES_HAS_CPP17_BOOL_CONSTANT

Please correct widespread deprecation warning in hslw_expressionset

Modernizing bslmf_integralconstant

Replace all usage of deprecated platform macro BSLS_PLATFORM_CMP_AIX

fix TSAN issues in bdlcc_skiplist.t.cpp

Remove BDE support for legacy SunOS operating system

Revivify bsls_ident

Reduce bslmt TSAN issues

balb_filecleanerutil::removeFiles - touch up asserts, logic

Fix asan leak in bdlma_concurrentpoolallocator

Fix asan leak in bdlma_countingallocator

Fix BALL performance regression introduced by kernel TIDs

Reenable building bde without internal deprecations nor transitive includes

baljsn::Decoder maxDepth failure
