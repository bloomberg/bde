Conversion between BAS Message Objects and bdljsn::Json

The new component, baljsn_jsonconverter, provides two utility functions:

  1. one that copies values from a bdlat-compatible object (the representation used for BAS Messages) to a bdljsn::Json object having an analogous organization, and

  2. another that provides the inverse operation – that copies values from a bdljsn::Json object to a compatible bdlat object.

Note that these conversion are done directly between the objects – i.e., there is no intermediate textual representation of the JSON object.

Consider test::Employee, a bdlat-compatible class generated by bas_codegen.pl` from a ``test_employee.xsd schema file.

First, create an instance of that class and set its values

test::Employee employee;
employee.name()                 = "Bob";
employee.homeAddress().street() = "Lexington Ave";
employee.homeAddress().city()   = "New York City";
employee.homeAddress().state()  = "New York";
employee.age()                  = 21;

Now, create a baljsn::JsonConverter object and call the convert method to load a newly created bdljsn::Json object with values from employee.

baljsn::JsonConverter converter;
bdljsn::Json          employeeJson;

int rc = converter.convert(&employeeJson, employee);
assert(0 == rc);

Then, examine the values of the employeeJson object for comparison to those of employee:

{
    "age": 21,
    "name": "Bob",
    "homeAddress": {
        "street": "Lexington Ave",
        "state": "New York",
        "city": "New York City"
    }
}

Finally, convert jsonEmployee back to a test::Employee object that is equals the initial employee object.

test::Employee employeeFromJson;
rc = converter.convert(&employeeFromJson, jsonEmployee);
assert(0        == rc);
assert(employee == employeeFromJson);
